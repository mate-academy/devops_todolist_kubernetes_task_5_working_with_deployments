# Інструкція розгортання K8s
# Встановлення необхідних залежностей додатка
pip install -r requirements.txt

# Виконання міграцій бази даних SQLite
python manage.py migrate

# Локальний запуск сервера розробки Django
python manage.py runserver

Головна сторінка та API списків справ: http://127.0.0.1:8000/

Створення простору імен
kubectl create namespace mateapp
# Застосування маніфестів розгортання та автоскалювання
kubectl apply -f deployment.yml
kubectl apply -f hpa.yml

# Обґрунтування конфігурації
Requests (200m CPU / 256Mi RAM): мінімум для стабільного старту Django-додатка та коректного розподілу подів планувальником.

HPA (min: 2, max: 5): 2 поди забезпечують базову відмовостійкість додатка, а максимум у 5 подів обмежує надмірне використання ресурсів.

Межа у 512Mi RAM та 500m CPU слугує захистом кластера від перевищення та монополізації ресурсів однією под-системою, а також забезпечує необхідний резерв для стабільної роботи додатка під час короткочасних пікових навантажень

HPA (70%): Стандартний поріг масштабування, який залишає 30% запасу, поки створюються нові поди під навантаженням.

RollingUpdate (maxSurge: 1, maxUnavailable: 0): Гарантує деплой без простою (Zero-Downtime). Старі поди активні, поки нові не перейдуть у статус Ready.

# Доступ до додатка
kubectl port-forward deployment/todoapp 8000:8000 -n mateapp
Посилання для браузера: http://localhost:8000/
